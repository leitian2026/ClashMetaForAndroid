## 162. 测 IP 结果表与已保存 IP 共用同一张表

- **统一数据：** 保存一批时，将每个 IP 的完整 IpTestRow 快照及直连 / 套入节点 / 目标网址模式写入所选运营商；实时日志不保存。旧记录和粘贴 IP 的结果快照为空，结果列显示“-”。未测出的项目按结果表空值规则显示“-”。
- **机房信息：** 运营商分组同时保存测试报告提供的机房城市名和国家代码映射，已保存表继续使用测试页同一套国旗、机房名称与单元格渲染逻辑。旧 JSON 通过新增字段默认值兼容。
- **表格：** 展开运营商后显示单张表，IP 固定在左侧，结果列横向滚动；列为三种模式的语义并集，出口国家统一为一列，直连端口检测与节点端口统一为一列。不适用于某条 IP 的列显示“-”；不保存实时日志；#158 的直连 / 经节点下载测速入口作为独立操作列显示，不属于原始测试快照。普通文字列最多显示 3 行，并按当前自选列及该运营商组内实际显示的数据计算所需列宽；内容放不下就加宽列，整表超过可用宽度时横向滚动，不通过压窄文字列来增加行高。行高按 IP 格、全部结果文字格和测速按钮格测量后的最高值确定，并留出额外上下空间；速度格不自画底色，只由整行画条纹或选中色；已保存页条纹约 4%（colorSavedStripe），与测 IP 页的 colorStripe 分开；深色模式下 colorHighlight 无主题值时回退白色，因此使用 4% 白色条纹；直连 / 经节点按钮默认两行高度，只有速度大于 0 且 Short=true 时显示第三行 11sp 橙色“不足30M”（过窄显示“<30M”）；对应行左右高度同步，表头固定为名称、MB/s、排序标签三行。已保存页两测速列按三行表头和按钮文字实测最小列宽，第三行提示不撑宽列。 已保存页的直连 / 经节点测速列宽按三行表头（名称、MB/s、排序标签）和两行按钮文字的实际测量值取最小需求，不再沿用固定 96dp；配置检查页及其他列宽不变。
- **复用与性能：** 表头、单元格、列宽计算和 IP 单元格均复用 IpTestView，不另建第二套表格。已保存页现使用运营商分组整表布局，详情见 #163；此处优化仅针对配置检查页的实时结果表。
- **功耗 / 计算量：** 已保存测速列宽只在原有表格重建时实测一次；下载和 Short 状态更新仍由用户点击触发，不新增定时器、轮询、后台任务或网络请求。 条纹色常量仅初始化时计算一次；速度格少绘制容器和按钮两层背景，不新增 View，也不改变表格重建、行高测量及选中状态更新流程。\n- **相同结果跳过重绘（r335）：** setRows() 先比较排序后的行数据和推荐集合；两者均未变化时直接返回，不重建主表或诊断表。行数据变化时重建主表；仅节点模式或目标站模式更新诊断表，直连无目标站模式不做无用诊断表更新。
- **归属查询局部更新（r335）：** 通过 IP 缓存归属运营商单元格 View；查询开始 / 结束时只更新受影响 IP 的“查询中”单元格。若对应单元格不存在则回退整表重绘。表格排序、内容、行高和诊断原文保持不变，不做增量追加行。
- **交互：** 保留 IP 点击复制、长按行多选等现有交互；测试页原有探测、下载测速和诊断内容不变。
- **改动文件：** SavedIpStore.kt、IpTestView.kt、SavedIpDesign.kt、ConfigCheckDesign.kt、本详情及 CUSTOM.md；#158 另修改下载测速请求与保存入口。
- **验证范围：** 静态核对保存字段、默认值兼容、表格共用渲染入口、按本行最高单元格确定行高和行级更新；未运行构建或设备测试。
