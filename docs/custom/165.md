## 165. 已保存页表头闪屏与按运营商局部重建（r311）

- **表头闪屏修复（r308）：** 页面不监听窗口焦点变化做整页重绘。表头筛选弹窗只在复选项真的变过时，关闭后重绘；只点空白处关闭不重绘。弹窗打开期间不改表头摘要，关闭后随一次重建更新。
- `IpTestView.savedTableView` 用一次性的 pre-draw 监听在首帧绘制前恢复横向滚动位置，不用 `post` 延后一帧。
- **按运营商局部重建（r311）：** 每个运营商对应一个独立 section View，并按运营商 ID 缓存。状态单选、表头筛选只替换受影响运营商的 section；不会销毁其他运营商已展开的表。r330 起，已进入多选模式后的单行勾选 / 取消直接更新该行复选框与背景，不替换 section；首次进入多选和取消最后一项退出多选时，因复选框列需要出现 / 消失，才重建当前运营商 section。搜索关键词变化、整页数据刷新、展开 / 收起运营商仍重建整页；速度排序是全页共用方向，切换时重建所有展开运营商。
- **滚动查找优化（r334）：** 建表时按运营商 ID 缓存展开表格 View；滚动吸顶更新直接读取缓存，只检查有表格的运营商，并跳过高度为 0 的表格，不再在每次滚动时调用 `findViewWithTag` 遍历视图树。整页重建或单运营商 section 移除时同步清理对应缓存；吸顶表头副本、横向滚动同步和原有布局不变。
- **状态与滚动：** 保持搜索时所有匹配运营商展开；各运营商状态筛选互不影响。横向滚动位置继续由 `IpTestView.savedTableView` 的 pre-draw 恢复逻辑处理，未改回 `post`。筛选弹窗打开期间不改表头。
- **范围：** 只涉及已保存 IP 页；不改普通 IP 测试页、筛选规则、列宽、测试请求或 mihomo。不新增定时器、轮询或动画。
