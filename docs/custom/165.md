## 165. 修复已保存页表头闪屏（r308）

- **现象：** 已保存 IP 表格里，表头筛选勾选 / 取消、速度表头选“按最快 / 按最慢”时表头会闪一下，速度表头最明显；点开筛选弹窗或点弹窗外空白处关闭时也可能闪。
- **原因（三处）：**
  1. 页面曾监听窗口焦点恢复并无条件重绘整页；可聚焦的 PopupWindow 打开 / 关闭会触发焦点变化，整个列表被销毁重建。
  2. 重建后的新表横向滚动位置从 0 开始，下一帧才用 `post` 跳回原位置；速度列靠右，所以先看到表格回到最左再跳回来。
  3. 筛选弹窗里每勾一次，就实时改表头摘要行的显示 / 隐藏，而表头单元格高度是固定的，列名会被挤得上下跳；关闭弹窗后又整表重建一次，等于变化两次。
- **现在的样子：**
  - 页面不再监听窗口焦点变化做整页重绘。表头筛选弹窗只在复选项真的变过时，关闭后重绘一次以应用筛选；只点空白处关闭不重绘。
  - `IpTestView.savedTableView` 用一次性的 pre-draw 监听在首帧绘制前把横向滚动位置设回 `scrollX`，不再用 `post` 延后一帧。
  - 弹窗打开期间不再改表头摘要；摘要在关闭弹窗后的那一次重建里一并画出。
- **范围：** 只改 SavedIpDesign.kt 的表头弹窗回调和 IpTestView.kt 的 savedTableView 滚动恢复；不改筛选规则、选项、表格布局、列宽、测试页和 mihomo。pre-draw 监听只触发一次并自行移除，不新增轮询、定时器或动画。
- **验证：** 静态核对三处触发路径；未运行构建、未触发 Actions、未做真机交互测试。
