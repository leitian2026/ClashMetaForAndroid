## 163. 已保存 IP 上限与整表滚动

- **新保存上限：** `SavedIpStore.MAX_IP_COUNT` 调整为 300。仅当本次保存要新增 IP 且保存后总数超过 300 时拒绝；覆盖更新已有 IP 不算新增。
- **旧数据保留：** 不自动删除或截断已有记录。旧记录即使超过 300 仍可读取、备份、恢复、编辑和删除；普通写入及备份校验不再用新保存上限拦截。旧记录总数降到 299 以下后，才可再新增，新增后最多到 300。
- **提示：** 中英文提示使用同一常量参数，显示 300，说明这是总数上限，原有记录会保留。
- **展开行为：** 正常点击运营商时只更新单个 `expandedOperatorId`，因此其他运营商自动收起。搜索时匹配的运营商仍全部展开，保持原有行为。
- **表格布局：** 已保存页不再使用 `RecyclerView`，使用普通纵向滚动容器。每个展开运营商只创建一张表；IP 列固定在左侧，表头和全部结果行放在同一个横向滚动容器中，不再每行创建独立横向滚动容器。表格单元格、表头、列宽及 IP 单元格继续复用 `IpTestView`。
- **多选交互修正：** 非多选状态不显示选择框；长按任意 IP 进入该运营商的多选状态，所有行在 IP 左侧显示 CheckBox，长按行立即勾选；点击 CheckBox 或 IP 地址均可勾选/取消，选中行同时显示背景标记。多选状态下点击未选中的 IP 不再复制地址；退出多选后隐藏所有选择框。保留单运营商选择、最多 20 条及现有批量重测/删除逻辑。
- **其他保留交互：** 搜索、状态/国家筛选、排序、非多选状态下复制 IP、批量重测和批量删除保持原有行为；搜索展开规则不变。
- **改动文件：** `SavedIpStore.kt`、`SavedIpDesign.kt`、`IpTestView.kt`、中英文 `strings_custom.xml`、本详情及 `CUSTOM.md`。
- **验证范围：** 静态核对存储限制仅作用于新增、旧数据写入路径、单运营商展开、整表单滚动及多选控件显隐/点击回调；未运行 Android 构建或设备交互测试，未打包，未修改 mihomo。
