## 160. 已保存 IP 按国家多选筛选

- **筛选入口：** 在已保存 IP 页面状态筛选和排序行下方增加国家筛选入口。国家选项从当前保存清单已有的有效两位国家代码动态生成，并使用系统本地化国家名称和国旗显示；不新增网络查询。
- **多选规则：** 可同时选择多个国家；多个国家之间按“或”匹配。未选择国家时不限制国家。
- **组合规则：** 国家筛选与现有通 / 不通 / 未测试单选状态筛选、地址搜索按“且”组合。国家筛选不改变状态筛选的单选行为，搜索仍只匹配 IP 地址。
- **删除后的状态：** 每次刷新列表时，将已选国家与当前清单仍存在的国家代码对齐；某国家最后一个 IP 被删除后，该国家自动从选中集合移除，按钮计数同步更新。
- **状态与存储：** 国家选择只保存在当前页面实例内，不写入 SharedPreferences 或备份。切换国家筛选会退出现有整组 IP 多选操作，避免筛选变化时保留隐藏的 IP 选择。
- **代码组织：** 新增 SavedIpCountryFilter.kt，纯函数负责收集国家代码和按国家筛选；SavedIpDesign.kt 只保留页面状态、对话框及列表挂钩。国家代码收集使用序列处理，并在返回前通过 `.toList()` 物化为声明的 `List<String>`，避免 Kotlin 编译时的返回类型不匹配。
- **改动文件：** 新增 `design/src/main/java/com/github/kr328/clash/design/custom/SavedIpCountryFilter.kt`、`docs/custom/160.md`；修改 `design/src/main/java/com/github/kr328/clash/design/custom/SavedIpDesign.kt`、英文和中文 `strings_custom.xml`、`CUSTOM.md`。本次编译修正仅修改 `SavedIpCountryFilter.kt`，并同步更新本详情和 `CUSTOM.md` 版本 / 索引登记。
- **验证：** 已核对函数声明返回 `List<String>`，序列链在末尾调用 `toList()`；国家选项去重和格式过滤、多国家 OR、空选择不限制、国家与状态 / 搜索 AND、删除最后一个国家 IP 后自动取消选择、原状态单选逻辑均未改动。未实际运行 `bash scripts/check-custom.sh`，未在本地运行编译或真机测试；需以 GitHub Actions 构建确认修复。
