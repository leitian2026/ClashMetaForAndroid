## 160. 已保存 IP 按落地国家多选筛选

- **国家来源：** 使用 `IpTestRow.country`，即同一临时节点、同一待测 IP 请求回显服务（`api.country.is`，失败再用 `ipinfo.io/country`）得到的落地国家；这是回显服务报告的落地国家，不是目标站自行判断的国家。`IpTestRow.geo` 是 `ipinfo.io` 返回的 IP 登记国家，两者不可混用。`SavedIpEntry.exitCountryCode` 独立保存落地国家，`countryCode` 仍保留登记国家含义。
- **旧数据兼容：** 旧 JSON 没有 `exitCountryCode` 时默认为空字符串，不迁移、不自动写回。旧条目重测前没有落地国家，因此不出现在落地国家选项中，也不显示国旗；选择某国家时不匹配这些条目。直连测只有配置中存在 `server` 等于输入域名的节点时才查询落地国家；没有匹配节点时显示 `-`，保存后该字段为空，国家选项和国旗也不显示。
- **重测合并：** 新结果 `row.country` 非空时更新落地国家；为空时保留本批次或原保存条目已有的 `exitCountryCode`，不覆盖为空。
- **入口与选项：** 点击顶部“落地国家”按钮，在按钮下方打开可滚动下拉列表。国家选项从当前保存清单的有效落地国家代码动态生成，显示国旗和本地化名称；不新增网络查询。
- **多选与组合：** 可同时选择多个国家，多个国家之间按 OR 匹配；状态和 IP 搜索与国家筛选按 AND 组合。未选择国家时不限制国家。勾选后菜单保持打开，切换国家会退出整组 IP 多选；国家弹层与状态、排序菜单互斥，同一时刻只显示一个。
- **状态恢复：** 已选落地国家由 `SavedIpFilterState.kt` 管理，通过 Activity 实例状态保存和恢复。刷新清单后，已选国家与当前仍存在的落地国家代码对齐。
- **代码：** `SavedIpCountryFilter.kt` 负责落地国家代码收集和过滤；`SavedIpStore.kt` 负责持久化；`SavedIpDesign.kt` 负责国旗、菜单及列表挂钩。
- **验证：** 静态核对 `row.country` 保存、空值保留、旧 JSON 默认值、无匹配节点时为空、筛选与国旗使用同一字段；不增加定时器、轮询或网络请求。Android 构建待统一验证。
