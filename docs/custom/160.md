## 160. 已保存 IP 按出口国家多选筛选

- **国家来源：** 使用 `IpTestRow.country`，即同一临时节点查询得到的出口国家（目标网站看到的国家）；不使用 `IpTestRow.geo`（IP 登记国家 / 归属地）。`SavedIpEntry.exitCountryCode` 独立保存出口国家，`countryCode` 仍保留归属地含义。
- **旧数据兼容：** 旧 JSON 没有 `exitCountryCode` 时默认为空字符串，不迁移、不自动写回。旧条目重测前没有出口国家，因此不出现在国家选项中，也不显示国旗；选择某国家时不匹配这些条目。
- **重测合并：** 新结果 `row.country` 非空时更新出口国家；为空时保留本批次或原保存条目已有的 `exitCountryCode`，不覆盖为空。
- **入口与选项：** 点击顶部“国家”按钮，在按钮下方打开可滚动下拉列表。国家选项从当前保存清单的有效出口国家代码动态生成，显示国旗和本地化名称；不新增网络查询。
- **多选与组合：** 可同时选择多个国家，多个国家之间按 OR 匹配；状态和 IP 搜索与国家筛选按 AND 组合。未选择国家时不限制国家。勾选后菜单保持打开，切换国家会退出整组 IP 多选。
- **状态恢复：** 已选国家由 `SavedIpFilterState.kt` 管理，通过 Activity 实例状态保存和恢复。刷新清单后，已选国家与当前仍存在的出口国家代码对齐。
- **代码：** `SavedIpCountryFilter.kt` 负责出口国家代码收集和过滤；`SavedIpStore.kt` 负责持久化；`SavedIpDesign.kt` 负责国旗、菜单及列表挂钩。
- **验证：** 静态核对 `row.country` 保存、空值保留、旧 JSON 默认值、筛选与国旗使用同一字段；不增加定时器、轮询或网络请求。Android 构建待统一验证。
