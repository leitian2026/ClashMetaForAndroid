## 160. 已保存 IP 按国家多选筛选

- **筛选入口：** 与状态筛选和排序位于同一顶部工具栏；点击“国家”在工具栏下方原地展开国家列表，不使用弹窗。列表设置最大高度并可内部滚动。
- **国家选项：** 从当前保存清单已有的有效两位国家代码动态生成，并使用本地化国家名称和国旗显示；不新增网络查询。
- **多选规则：** 可同时选择多个国家；多个国家之间按“或”匹配。未选择国家时不限制国家。勾选或取消后立即更新筛选结果。
- **组合规则：** 国家筛选与状态多选、地址搜索按“且”组合；状态筛选为全部 / 通 / 不通 / 未测试单选。搜索仍只匹配 IP 地址。
- **删除后的状态：** 每次刷新列表时，将已选国家与当前清单仍存在的国家代码对齐；某国家最后一个 IP 被删除后，该国家自动从选中集合移除，按钮计数同步更新。
- **状态与存储：** 国家选择由页面状态统一管理，并通过 Activity 的实例状态恢复；不写入保存数据。切换国家筛选会退出现有整组 IP 多选操作，避免筛选变化时保留隐藏的 IP 选择。
- **代码组织：** `SavedIpCountryFilter.kt` 负责纯国家代码收集和过滤；`SavedIpDesign.kt` 负责工具栏入口、原地国家面板和列表挂钩。国家代码收集在序列链末尾调用 `.toList()`，返回声明的 `List<String>`。
- **r287 改动文件：** `design/src/main/java/com/github/kr328/clash/design/custom/SavedIpDesign.kt`、本登记文件和 `CUSTOM.md`。
- **验证：** 静态核对国家选项来源、国旗及本地化名称、多国家 OR、空选择不限制、国家与状态 / 搜索 AND、原地多选、面板滚动、删除最后一个国家 IP 后自动取消选择；未运行构建，由用户手动构建验证。

- **r290 状态筛选修正：** 状态由多选并集改为 `IpFilter` 单选；状态值通过 Activity 实例状态保存与恢复，旧多选 Bundle 不存在等价单选项时恢复为“全部”。国家多选逻辑保持不变。
