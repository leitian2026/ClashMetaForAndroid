## 160. 已保存 IP 表头按列多选筛选（r303）

- **入口：** 删除已保存页工具栏原“落地国家”筛选按钮及其独立筛选逻辑。改为点击已保存表格中可筛选列的文字表头，打开原有样式的可滚动复选框弹窗；弹窗保持打开以支持同列多选，点击同一表头可关闭，外部点击可关闭。
- **可筛选列：** 入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站反应。丢包率、最小 / 最大 / 平均延迟、抖动、分段耗时、速度及其他非文字列不可点击筛选。
- **选项来源：** 仅从当前运营商表已有保存结果生成选项，复用 IpTestView 已保存表格的字段映射与显示值；不发起网络查询。无结果、空值和显示为“-”的单元格不生成选项。保存、删除、重测后刷新时重新计算；所有运营商的数据中都不存在的已选值自动清除。
- **国家数据兼容：** 登记国家仍来自 `IpTestRow.geo`，落地国家仍来自 `IpTestRow.country`；`SavedIpEntry.countryCode` 与 `exitCountryCode` 继续分别保存这两个含义，旧 JSON 缺失字段仍按空值读取。表头筛选只采用当前表格单元格实际显示的结果，不把旧快照的空值替换成存储字段里的国家代码。
- **组合规则：** 同一列多个值按 OR 匹配；不同列按 AND 匹配。表头筛选与状态筛选、IP 搜索继续按 AND 叠加。没有选择任何表头筛选时，旧 IP（无测试快照）仍正常显示；选中某列值后，旧 IP 因该列无值而被过滤。
- **表头状态：** 已选值显示在对应列名下方；单值显示完整值，多值显示首个值及“+N”数量提示。IP 固定列、表格列宽、横向滚动和数据行不改变。
- **状态恢复：** 各列所选值由 SavedIpFilterState.kt 管理，通过 Activity 实例状态保存和恢复；旋转屏幕后恢复筛选。弹窗本身不保存。
- **范围：** 只作用于已保存页的 savedTable = true 表格。普通 IP 测试页表头和交互不变。保留状态筛选（全部、通、不通、未测试）、搜索、排序；不新增定时器、轮询或后台任务，不改 mihomo。
- **改动文件：** SavedIpDesign.kt、IpTestView.kt、SavedIpFilterState.kt、删除已废弃的 SavedIpCountryFilter.kt、本详情及 CUSTOM.md。
- **验证：** 完成源码静态核对；未运行构建、设备交互或打包，未触发 Actions。
