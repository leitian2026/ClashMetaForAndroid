## 122. 修正 YAML 跳转引用类型与正则零宽匹配边界（r140）
- **YAML 跳转：** 将 Walker 中所有引用统一为公开 Link 类型，确保 links(text) 返回的 refs 覆盖块列表、流列表和 rules 三类引用。
- **正则：** 搜索超时后不再立即重启第二轮搜索；替换当前项先确认光标选区确实对应非零长度匹配，再展开替换串，避免把普通的“当前选区不匹配”误报为替换表达式错误。替换时跳过同一位置的零宽匹配。
- **改动文件：** YamlLint.kt、CodeEditText.kt、TextSearch.kt 和本登记文件。
- **验证：** 静态检查引用构造点、零宽跳过和超时路径；未运行 JVM 测试或 Android 编译。
