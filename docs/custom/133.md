## 133. 修复历史版本比较的哈希参数类型错误（r151）

- **修正：** 改为调用已有的 `digestOf(file)`，复用文件 SHA-256 缓存，并保持先比较长度、再比较摘要的逻辑。
- **改动文件：** ConfigHistory.kt 和本登记文件。
- **验证：** 已根据 GitHub Actions 编译日志定位并修正；尚未对新提交重新运行 Android Debug 构建。
