## 171. 纯逻辑 JVM 测试

### 测试范围

通过 Kotlin 2.1.0 编译器直接编译并运行，不走 Gradle，不 checkout mihomo 子模块，不触发 Android / Go / NDK 构建。

仅测试以下三个不依赖 Android 的编辑器纯逻辑文件：

- `YamlLint.kt`：文本诊断、引用收集与定义解析。
- `YamlPairs.kt`：括号配对、引号范围。
- `TextSearch.kt`：普通 / 正则查找、计数、位置和替换。

### 暂未覆盖

以下逻辑暂不纳入本轮测试，因为它们依赖 Android API 或 `:core`：

- `CarrierSwitch.match`
- 已保存 IP 合并规则
- `ConfigDiff`
- `NetworkIdentityText`

本轮不为测试而搬动或修改这些生产源文件。`TextSearch.next()` / `prev()` 本身不负责首尾环绕；本轮测试按其源码行为验证边界返回 null，编辑器层的环绕由调用方负责。

### 运行方式

本地执行：

`bash scripts/run-custom-tests.sh`

脚本使用已设置的 `KOTLINC`；未设置时下载并缓存 Kotlin 2.1.0 编译器到 `${RUNNER_TEMP:-/tmp}`，编译三个源文件及 `tests/custom/*.kt`，然后用 `java -jar` 执行。

GitHub Actions：`.github/workflows/test-custom.yaml`，支持手动触发；推送到 `custom` 时，仅在三个被测源文件、测试文件、运行脚本或该 workflow 变化时运行。该流程与 Build Debug 独立，不运行 Gradle，不会阻塞 App 构建。
