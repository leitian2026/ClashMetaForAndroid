## 121. 收紧历史版本哈希缓存并规范 .stat 文件格式（r139）
- **哈希：** 文件摘要缓存改为以绝对路径为键、长度和修改时间校验的 HashMap，最多 64 项；超过容量时清空。文件摘要使用 8 KB 缓冲流式计算 SHA-256，不再一次性 readBytes。
- **比较：** same / find / isInUse / unapplied 均先比较长度，再比较摘要；文本摘要每次操作只计算一次。
- **收益范围：** 这项优化收益有限：只有长度相同的版本才会读取文件计算 / 查询摘要；主要在重复点击“应用”和反复打开历史列表时减少重复读取。
- **统计缓存：** Stat 仅包含行数、增加和删除行数；.stat 单行格式为 olderAt lines added removed，读取时校验更旧版本时间戳。历史列表命中缓存时不读取版本正文。
- **删除保护：** 删除前通过 inUse 查询当前已应用版本，避免删除它；remove 仍清理所有标记和 .stat。
- **改动文件：** ConfigHistory.kt、EditorActivity.kt 和本登记文件。
- **验证：** 静态检查缓存上限、分块读取、长度先行和统计缓存格式；未运行 Android 编译或文件性能测试。
