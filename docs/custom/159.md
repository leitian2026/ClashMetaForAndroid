## 159. 已保存 IP 列表排序

- **入口：** 顶部“排序”按钮下方的锚定下拉菜单，不占用列表布局空间；与状态、落地国家筛选弹层互斥，同一时刻只显示一个。
- **选项：** 默认（最近测试时间优先）、平均延迟低到高、下载速度高到低；当前项带勾，单选。
- **规则：** 每个运营商组内独立排序，不改变组顺序；平均延迟或下载速度为 0 的条目排在该指标排序末尾；相同数值保持默认顺序。整组多选时仍应用当前排序。
- **状态：** 由页面状态持有，并通过 Activity 实例状态恢复；不写入保存数据。
- **代码：** `SavedIpSort.kt` 实现纯排序逻辑；`SavedIpDesign.kt` 提供菜单入口和调用挂钩。
- **验证：** 已静态核对三种排序、零值置后、同值稳定排序、组内排序及菜单锚定；Android 构建待统一验证。
