## 159. 已保存 IP 双测速列独立排序

- **入口：** 直连测速、经节点测速两个表头都可点击，各自打开“按最快 / 按最慢”菜单。
- **状态：** 每个运营商独立保存自己的测速列和方向；同一运营商同一时间只对一列排序，选择另一列会替换该运营商当前排序。不同运营商互不影响。当前列下方显示方向标签，另一列不显示。再次选择当前方向取消排序，恢复默认测试时间新到旧顺序。
- **方向：** 按最快为速度从大到小；按最慢为速度从小到大。两种方向均只读取所点列自己的值：直连列只读 speedDirect，经节点列只读 speedNode，不混用或取两列最大值。
- **稳定性：** 速度为 0 或未测的项目始终排最后；同速保持默认顺序。每个运营商组内独立排序，不改变运营商组顺序。速度排序只在当前展开组计算，并按数据版本和排序选项缓存；筛选只从缓存顺序中取行，不因滚动或绘制重复排序。
- **旧状态：** 旧版 SPEED_ASCENDING / SPEED_DESCENDING 没有列信息且方向语义错误，恢复时安全重置为默认顺序；新状态持久化列和方向，未知值也回退默认，不会导致崩溃。
- **隐藏列：** 只有当前生效的测速列被隐藏时才清除排序；隐藏另一列不影响当前排序。直连和经节点列分别判断。
- **显示：** 表头固定为“直连 / 经节点”名称、MB/s、排序标签三行；按钮默认两行文字均为 14sp，第一行显示短名称，第二行只显示一位小数速度值，不带单位；仅速度大于 0 且 Short=true 时增加 11sp 橙色第三行“不足30M”，放不下则显示“<30M”，单行不换行。按钮置于单元格容器内，容器四周留白；按钮高度按两行 / 三行文字的实际排版高度分别计算。未测速时保留第二行空位，有速度、未测速、测速中或失败状态均不改变对应模式的按钮尺寸；完整名称资源继续用于自选列与完成提示。测速结果回来仍只更新对应行的对应按钮；Short 状态变化时仅更新该行并同步左右行高，不重建整表或重新计算列宽。
- **代码：** SavedIpSort.kt 按选中列稳定排序；SavedIpFilterState.kt 保存新状态并兼容旧数据；SavedIpDesign.kt 管理菜单、缓存和隐藏列；IpTestView.kt 开放两个测速表头。
- **验证：** 静态核对最快 / 最慢方向、两列独立取值、零值置后、同值稳定、切换列和取消排序、旧状态回退；未运行 Android 编译或设备交互。
