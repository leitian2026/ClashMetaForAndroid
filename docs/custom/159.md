## 159. 已保存 IP 列表排序

- **排序选项：** 在状态筛选按钮同一行增加“排序”入口，弹出单选列表，提供默认（沿用现有测试时间新到旧）、平均延迟低到高、下载速度高到低三种排序。
- **排序规则：** 先按现有默认顺序建立基准；平均延迟或下载速度为 0 的条目排在该排序末尾。相同数值保持基准顺序，确保稳定排序。
- **作用范围：** 每个运营商组内独立排序，不改变运营商组顺序。普通筛选结果和“选中整组”时显示的完整列表都使用当前排序；状态筛选、搜索仍按原逻辑生效。
- **状态与持久化：** 排序选择仅在当前页面实例有效，不写入保存数据；重新进入页面恢复默认排序。原有通 / 不通 / 未测试筛选仍是单选，不作改动。
- **代码组织：** 纯排序逻辑位于新增 SavedIpSort.kt；SavedIpDesign.kt 只保留排序状态、入口和调用挂钩。
- **改动文件：** 新增 design/src/main/java/com/github/kr328/clash/design/custom/SavedIpSort.kt、docs/custom/159.md；修改 design/src/main/java/com/github/kr328/clash/design/custom/SavedIpDesign.kt、英文和中文 strings_custom.xml、CUSTOM.md 功能一览。
- **验证：** 静态核对三种排序、零值置后、同值稳定、运营商组内排序、整组选中列表排序及页面内状态；未实际运行 bash scripts/check-custom.sh，未运行编译或真机测试。
