## 159. 已保存 IP 速度排序（r304）

- **入口：** 删除顶部独立“排序”按钮，改为点击已保存表格的“速度”文字表头。
- **选项：** 仅有“按最快”和“按最慢”。再次选择当前方向时取消排序，恢复默认测试时间新到旧顺序；当前方向显示在速度表头下方。
- **规则：** 只按下载速度排序，任何延迟列都不参与排序；#158 起按直连与经节点两种测速结果中的较大值排序。无速度数据（速度为 0）的 IP 始终排在最后；相同速度保持默认顺序。排序在每个运营商组内独立应用，不改变运营商组顺序。
- **状态：** 排序方向由 SavedIpFilterState.kt 保存，通过 Activity 实例状态恢复；不写入保存数据。
- **代码：** SavedIpSort.kt 实现稳定排序；SavedIpDesign.kt 提供表头菜单；IpTestView.kt 显示速度表头摘要并只为已保存表格开放该入口。
- **验证：** 静态核对最快 / 最慢方向、无速度项置后、同值稳定排序和默认顺序恢复；未运行 Android 构建或设备交互。
