## 159. 已保存 IP 列表排序

- **排序入口：** 与放大镜、状态筛选、国家筛选位于同一顶部工具栏；点击“排序”在工具栏下方原地展开选项，不使用弹窗。
- **排序选项：** 默认（沿用现有测试时间新到旧）、平均延迟低到高、下载速度高到低。
- **排序规则：** 先按现有默认顺序建立基准；平均延迟或下载速度为 0 的条目排在该排序末尾。相同数值保持基准顺序，确保稳定排序。
- **作用范围：** 每个运营商组内独立排序，不改变运营商组顺序。普通筛选结果和“选中整组”时显示的完整列表都使用当前排序；状态筛选、搜索仍按原逻辑生效。
- **状态与持久化：** 排序选择保存在当前页面状态中，并通过 Activity 的实例状态恢复；不写入保存数据。
- **代码组织：** 纯排序逻辑位于 `SavedIpSort.kt`；`SavedIpDesign.kt` 负责工具栏入口、原地选项面板和调用挂钩。
- **r287 改动文件：** `design/src/main/java/com/github/kr328/clash/design/custom/SavedIpDesign.kt`、本登记文件和 `CUSTOM.md`。
- **验证：** 静态核对三种排序入口、原地展开、选择后即时更新、零值置后、同值稳定、运营商组内排序及整组选中列表排序；未运行构建，由用户手动构建验证。
