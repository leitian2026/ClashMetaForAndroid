## 43. 测试其他 IP（配置检查页；输入历史、域名解析及已保存 IP 提示）
**效果：** 配置检查页在"推算最终配置 / 清缓存 / 检查 DNS"那一行下面多一个"测试其他 IP"按钮，测**不在配置里**的 IP。点开是一个对话框：现有多行测试框只填 IP 地址（每行一个，也可以用逗号、分号、空格分隔，全角的也行；`1.1.1.1:443`、`[2606::1]:443` 取其中的地址，端口不用；重复的去掉；既不是 IP 的词在结果里列出来）；下面增加独立的域名输入框，点击“解析域名”后显示 IPv4 勾选列表，选中后点“放入测试框”会追加地址。域名输入记在页面自己的 SharedPreferences，解析结果不持久化。下面仍可选一个节点，两个按钮："直连测 IP"（A）和"套入节点测"（B）。测试框里的 IP 和选的节点记在页面自己的 SharedPreferences（`custom_config_check` 的 `ip_text`、`ip_node`）；域名输入单独保存。输入框文字变化只更新内存中的修改时间和标题，停手约 1 秒后通过一次性延迟任务保存；继续输入会取消并重排。解析结果时间标签继续使用分钟差辅助函数（r349 将该函数恢复为文件级私有函数，供解析结果标签调用）。确认、取消、返回键、点外面关闭或 Activity 销毁时通过所属协程取消主动关闭对话框；所有关闭路径均立即取消待执行任务并保存未落盘的输入；手动输入与一次性预填分别使用独立历史键，预填不覆盖 `ip_text`，内容未变化不更新时间戳。结果出来后，**点一行复制这个 IP**，最后一行"复制全部能用的 IP"；右上角的复制按钮复制整页文字。

**结果页的小字（ECH 配置来源、TLS 和运营商那一行、提示、时间）r46 起用深一点的灰（浅色 `#616161`，夜间 `#BDBDBD`），原来固定的 `#9E9E9E` 在浅色背景上太淡；只改了这一页，DNS 检查页（`DnsCheckView`）的 `#9E9E9E` 还没动。**

**一次最多 20 个**（多的不测，结果里写"还有 N 个没测"）。**一个接一个测，两个之间随机隔 1 到 3 秒**（`ipGapMin` / `ipGapMax`）。结果按延迟从小到大排，没通的排最后（按填的顺序）。测的时候按钮变成"取消"，再点一次，界面立刻停，同时通知内核停（`closeCustomConnection("!cancel-iptest")` → `CancelIPTest`），已经测完的行仍然显示（"已取消"）。点测试按钮才测，没有定时器、没有后台任务。

**A：直连测 IP（不经过节点）**
- **只测 IP 地址（r46）：** 填了域名的条目不测，结果里写"域名只能用套入节点测，这里没测：…"；只填了域名就直接提示"直连测 IP 只测 IP 地址，域名要用套入节点测"。
- 用输入框里**已有的那个域名**当 SNI 和 Host（没填会提示）；直连 `IP:443`，拨号用 `dialer.DialContext`（和 ECH 测试一样，不走 VPN）。
- 每个 IP 显示：延迟（连接 + TLS 握手，毫秒）、TLS 版本、ALPN（握手时给 `h2` 和 `http/1.1`，看服务器选哪个）、ECH 是否被接受、是不是 Cloudflare（实测）、机房；运营商 r48 起点一下才查（见 #45）。已经在某个节点的 `hosts:` 里的标"已在配置里"。
- **ECH：** 这一轮开头向 DoH 取一次这个域名的 ECH 配置（先配置里 `dns:` 的 `https://` 服务器，再几个公共的，一共最多等 8 秒）；取到了就带 ECH 握手（TLS 1.3），"已接受 / 未接受 / 被拒绝"；被拒绝时再用普通握手试一次，这个 IP 通不通、延迟多少看第二次；取不到就不带 ECH，页面写"这个域名没有查到 ECH 配置"。证书不验证，只看握手过没过。
- **机房：** 握手后在同一条连接上发一个 `HEAD /`，读 Cloudflare 的 `Cf-Ray` 响应头末尾的机房代号（例如 `HKG`）；不是 Cloudflare、或者没回应就不显示。连的是这个 IP 本身，所以读到的是它自己的机房。
- **运营商：** 先查 `ipinfo.io/<ip>/org`，没有再查 `ipwho.is`（两个都是公共服务，有频率限制），查到的记在内存里，下次不再查；查不到就不显示，不影响这个 IP 算不算通。**r48 起不再自动查，改成点一下才查，见 #45。**

**B：套入节点测**
- **旧 Go 域名分支保留（r46）：** 内核原有的 nodeone 域名处理代码不改；本页面从 r257 起在 UI 入口拦截测试框里的域名，必须先用独立域名框解析成 IPv4 并勾选填入。因此下面关于“域名替换 server”的内容只记录仍保留的 Go 分支，不代表当前对话框允许直接输入域名：条目是域名时，旧分支会把所选节点复制一份，`server` 换成这个域名（节点名另取 `<节点名> (test)`），其余和 IP 一样。域名由内核拨号时自己解析，所以 `hosts:` 里写了这个域名就用你写的 IP；节点没写 `servername` / `sni` 时 SNI 就是这个域名。**换名是为了避开 #42 的首选 IP**：内核按节点名认首选 IP，临时节点同名的话，域名解析结果里只要有首选 IP，就只会拨那一个，测出来的就不是这个域名本身了。域名行不查"已在 hosts"，也不读、不记国家缓存（国家照样查），因为那是按 IP 记的。域名合法性：至少两段，每段只含字母、数字、连字符（不以连字符开头结尾），最后一段要含字母（所以 `1.2.3`、`300.1.1.1` 不算域名）；中文域名要写成 punycode。
- 选的节点原样复制一份，只把 `server` 换成这个 IP，用节点自己的协议请求测速地址（`ipdelay.TryIP`，和 #1 逐 IP 测速是同一个做法，延迟数字可以直接比），通了再取落地国家（这个节点 + 这个 IP 已经知道国家就直接用）。每个 IP 显示：国旗（查不到显示"？"）、延迟、"已在 hosts"（这个节点的 `hosts:` 里已经有）。
- **没有"对照"（r309 起）：** 原来的"比对照快"列和页面顶上的"对照：…"一行已去掉。对照值来自代理页上一次测速、存在内存里，每次载入配置就清空，和这次测的 IP 也不是同一时刻测的，既常常没有数据、也不能说明哪个更快。内核不再计算它（`IPReport.Ref`、`IPRow.Faster` 字段留着，恒为空，只为旧的已保存结果还能读）。
- **局限：** 和 #1 一样只换 `server`，节点没写 `servername` / `sni`（或 Host）时，这些字段默认取 `server`，换成 IP 后就是这个 IP（vless 看过源码，其他协议没逐个看）；这时测出来的"不通"可能是这个原因，不是 IP 的问题。测的过程中我们自己的套接字会计入 `selfDialing`，不会被当成真实流量记进"在用的 IP"。

**已保存 IP 输入提示：** 提示直接画在原有测试框 `TextInputEditText` 内，每个命中的 IP 所在行正下方显示“已在保存的 IP 中”，不在输入框外增加提示布局，也不把提示文字写入输入内容。打开对话框时从 `SavedIpStore` 读取一次快照并构建缓存 `HashSet`；文字变化时按换行逐行读取行首地址，到空白、逗号、`#`、分号等分隔符为止，沿用 `normalize` 去端口并与缓存集合比较，同一 IP 出现在多行时逐行标记。命中行使用 `LineHeightSpan` 为该行最后一个视觉行增加小字高度，再由 `LineBackgroundSpan` 在新增空隙中绘制 12sp 次要文字色提示；span 同时实现 `UpdateLayout`，使 `DynamicLayout.ChangeWatcher` 在 span 添加或移除时触发重新排版，确保 `afterTextChanged` 中更新 span 后立即应用行高，不依赖用户再次输入换行。绘制用的 `Paint` 在 span 构造时创建并复用。两个 span 都使用 `SPAN_EXCLUSIVE_EXCLUSIVE`。只在命中行范围变化时替换旧 span；提示不属于 `Editable` 内容，不影响复制、选择、识别、测试和光标。输入变化不重新读取 Store、不扫描已保存表、不为提示使用定时器或轮询。
