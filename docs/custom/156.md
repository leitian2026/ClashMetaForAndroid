## 156. 已保存 IP 清单（r177，排序规则修正补充）
- **独立存储：** 新增 `SavedIpStore.kt`，使用独立 SharedPreferences `custom_saved_ips`，JSON 保存运营商分组、IP 地址、最近状态、最近测试时间、加入时间和上次使用的运营商 ID；不复用最近一轮 IP 测试结果的 `ip_test_last`。
- **数据结构：** 内置运营商固定 ID 为 `telecom`、`unicom`、`mobile`，内置名称留空，后续由字符串资源提供；自建运营商保存独立 ID 和名称。IP 状态仅为 `UNTESTED`、`REACHABLE`、`UNREACHABLE`。`countryCode` 保留 IP 登记国家（`row.geo`）；`exitCountryCode` 独立保存 `row.country`（落地国家），两者不混用。旧 JSON 缺少 `exitCountryCode` 时默认为空字符串，不迁移、不自动写回。每条 IP 另存 `lastTestedAt`（最近测试时间，Unix 毫秒）和 `addedAt`（加入时间，Unix 毫秒）；旧 JSON 缺少字段时默认按 0 读取。
- **读写：** `read()` 只读取和规范化内存数据，不写偏好；仅显式调用 `write()` 时序列化并通过 `SharedPreferences.apply()` 保存。读取损坏或缺失的数据时回退为空清单，不触发自动迁移写入。
- **筛选与搜索状态：** 状态筛选使用 `IpFilter` 单选：全部、通、不通、未测试，每次只能选择一个状态；按钮和菜单当前项使用同一状态颜色；落地国家筛选只读取 `exitCountryCode`，不回退到 `countryCode` / `geo`；状态、落地国家和搜索按 AND 组合。重测时若 `row.country` 为空，保留该条目原有落地国家代码。单个状态值、落地国家、排序、搜索关键词、搜索展开状态和已展开运营商 ID 统一由 `SavedIpFilterState.kt` 管理，并通过 Activity 的实例状态保存与恢复。搜索默认仅显示放大镜，点击后在同一工具栏行展开、自动聚焦并弹出键盘；输入框内清除按钮只清空关键词，关闭按钮只收起搜索并保留关键词，放大镜以提示圆点标记仍有关键词。搜索只匹配 IP 地址并忽略大小写；窄屏时落地国家和排序按钮自动换到第二行；打开状态、落地国家或排序下拉菜单时先收起搜索框。返回键先收起搜索框，再按 Activity 原有逻辑返回；状态、落地国家和排序三个筛选弹层互斥，同一时刻只显示一个；弹层由系统处理返回键和外部点击关闭。
- **分组与空列表（r289）：** 分组标题显示当前筛选、国家和搜索条件下实际展示的 IP 数量，通 / 不通 / 未测试数量也按当前展示清单统计，并以彩色小标签显示。展开箭头点击区域至少 48dp，三点菜单区域为 48×48dp；点击三点只打开菜单，不触发展开 / 收起。多选模式继续显示所选运营商的完整 IP 清单，绕过状态、落地国家和搜索过滤。过滤后没有结果时通过 RecyclerView 的 `SavedIpListRow.Message` 显示“没有符合条件的 IP”；原本没有保存 IP 时显示空清单提示。相同列表数据不重复触发全量刷新，窗口重新获得焦点时仍会安全调用渲染。
- **状态恢复：** 搜索关键词、搜索展开状态、单个状态值、落地国家、排序和已展开运营商 ID 均由 `SavedIpFilterState.kt` 保存；下拉菜单属于临时 UI，不写入实例状态。恢复搜索展开状态时恢复搜索框显示，不主动弹出键盘。
- **边界：** 不同运营商允许保存相同 IP；同一运营商内按地址去重。每个运营商按 `lastTestedAt` 从新到旧排列；未测试项（时间为 0）排在测试项之后，并按 `addedAt` 从新到旧排列。旧数据缺少时间字段时均按 0 处理，不崩溃；旧未测试项无法还原真实加入时间时保持原有相对顺序。全清单最多 5000 条，写入超过上限时拒绝，不静默截断。读取时补齐三个内置运营商，固定 ID 不依赖本地化名称。

- **当前页面实现：** 状态、国家、排序均使用按钮下方菜单；状态单选并显示完整保存清单计数，国家多选并保持菜单打开，排序单选。搜索默认收起，关键词只匹配 IP；收起不清空。分组统计按当前显示条目计算，整组多选绕过普通筛选和搜索；空结果使用 `SavedIpListRow.Message`。页面状态通过 `onSaveInstanceState` 保存和恢复，不改 Manifest。
- **当前涉及文件：** `SavedIpStore.kt`、`SavedIpCountryFilter.kt`、`SavedIpFilterState.kt`、`SavedIpSort.kt`、`SavedIpDesign.kt`、`SavedIpActivity.kt`、中英文 `strings_custom.xml`。
- **验证：** 静态核对存储兼容、落地国家保存与保留、落地国家筛选和国旗数据源；未运行本地 Android 构建。
