## 166. 测 IP 综合推荐前三名

- **标记：** 测 IP 结果表和已保存 IP 表分别最多标出前三个推荐地址，在 IP 地址前显示蓝色（主题色 `colorLink`）★；两页使用同一排序规则。
- **候选：** 必须有成功结果（`ok`）且至少发送过一次探测（`sent > 0`）。不把未完成、未测或失败结果纳入排名。
- **排序：** 依次比较失败率（使用结果保存的整数百分比，不再分档，越低越好）、平均延迟（20 ms 一档，`avg / 20`，即 0–19、20–39、40–59 ms）、抖动（越低越好）、下载速度（越高越好）。所有指标仍相同时保持原有输入顺序；最多取前三名。
- **已保存页：** 每个运营商分组独立排名；只用该运营商完整保存清单中的结果快照，排除连续失败次数 `failStreak > 0`、从未测试及距最近测试超过 7 天的记录。排名在应用状态筛选、搜索和表头筛选之前计算，因此不会因当前可见子集变化而改变。
- **计算与导出：** 纯本地计算，不发请求；测试结果更新时计算一次，已保存分组绑定时计算一次。只在 IP 单元格显示星标，不改变原有排序、测速和单元格内容；`plain()` 复制文本不加入星标。
- **改动文件：** 新增 `IpRecommend.kt`、本详情；修改 `IpTestView.kt`、`SavedIpDesign.kt`、`CUSTOM.md`。
- **验证范围：** 静态核对候选条件、稳定排序、20 ms 分档、每组完整数据范围及星标主题色；未运行 Android 构建或设备测试。
