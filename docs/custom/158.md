## 158. 已保存 IP 平均延迟与独立直连 / 经节点下载测速

- **原有指标：** 保留已保存 IP 的平均延迟 avg（毫秒）显示，保存测试结果时仍从 IpTestRow.avg 写入；不改变原有状态字段、状态圆点和状态筛选。
- **入口：** 已保存 IP 表格新增“直连测速”和“经节点测速”两个独立列。每行两个入口始终显示，包括原始 IP 探测失败或只有粘贴记录的 IP；点击后才发起对应测速。测速期间按钮禁用，完成后恢复。
- **请求复用：** 复用配置检查页 ConfigCheckActivity.runSpeed() 的现有 kind=ip、mode=download 请求链路，统一由 IpDownloadSpeed.kt 构造请求。下载仍通过 queryCustomConnections(CustomConnections.SORT_CHECK, request) 执行，不新增下载实现，不改 Go / mihomo。
- **模式与偏好：** 直连请求 node 为空；经节点从 SharedPreferences("custom_config_check") 的 ip_node 读取测试 IP 页面当前选中节点，并先查询 mode=nodes 验证节点仍存在。没有选择或节点已不存在时提示去测试 IP 页面选择节点，不回退主页 currentNode。URL 分别复用 ip_url_direct / ip_url_node 和原默认 URL。
- **保存数据：** 新增 speedDirect、speedNode，仅保存各自的速度数值，不保存节点名称。旧 speed 字段按 testDirect 迁移：直连记录迁移到 speedDirect，节点记录迁移到 speedNode。兼容 speed 值保持两种结果中的较大值。
- **排序和自选列：** 原速度排序按直连与经节点测速结果中的较大值排序，0 或无结果仍置后、同值保持默认顺序。两个测速列均进入自选显示列；旧版已有自选列配置会自动加入新增的经节点列。仅第一列速度表头提供原排序入口。
- **互斥与功耗：** 新增进程内事件驱动状态，配置检查页 IP 探测 / 下载测速与已保存页下载测速互斥；状态变化直接通知页面更新按钮，不使用定时器、轮询或后台测速。仅点击时运行。
- **改动文件：** 新增 app/src/main/java/com/github/kr328/clash/custom/IpDownloadSpeed.kt、IpSpeedTestCoordinator.kt；修改 ConfigCheckActivity.kt、SavedIpActivity.kt、SavedIpStore.kt、SavedIpSort.kt、IpTestView.kt、SavedIpDesign.kt、英文和中文 strings_custom.xml，以及本详情与 CUSTOM.md。
- **验证：** 静态核对请求字段、偏好键、旧速度迁移方向、两个按钮在失败结果行仍可见、互斥状态无轮询；未运行构建或真机测试。
