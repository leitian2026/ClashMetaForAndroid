## 158. 已保存 IP 独立直连 / 经节点下载测速

- **入口与列位置：** 已保存 IP 表左侧只有“IP 地址”列固定；右侧是一个整体横向滚动区域。“直连”与“经节点”两列位于该滚动区域最前面，紧挨固定 IP 列右侧，顺序为直连、经节点，原有其他列整体后移。两列不固定、不并入 IP 固定区。
- **请求：** 复用配置检查页现有 kind=ip、mode=download 下载测速请求，不另建下载实现。直连请求 node 为空；经节点使用配置检查页保存的 ip_node，并先校验节点存在。两种模式分别复用各自下载 URL 偏好。
- **旧数据：** 旧 speed 按 testDirect 迁移到 speedDirect 或 speedNode；未测值为 0 / sentinel，不自动发起测速。新增 speedDirectShort / speedNodeShort 两个默认 false 的布尔字段，旧快照缺少字段时不显示不足 30M 提示。
- **互斥与功耗：** 与配置检查页 IP 测试 / 下载测速共享事件驱动互斥；只在用户点击时发起，不用定时器、轮询或后台任务。测速状态变化只更新当前已绑定按钮，不重建整表。
- **结果更新：** 测速结束只更新对应行的对应速度按钮及其 Short 标记；标记和值在同一次 Store 写入。若当前启用了该列排序，仅移动现有行 View 到新位置，不重建表格或列宽。Short 状态变化时只重新测量并同步该行左右两侧行高，不扫描其他行；从 true 变回 false 时行高恢复。
- **布局：** 两列测速按钮各自放在独立容器内；容器占满对应滚动列单元格，按钮居中并与格子边缘留出间距，不直接被整行高度拉伸。默认按钮为 14sp 两行；只有该模式速度大于 0 且 Short=true 时增加第三行“不足30M”，11sp 橙色。第三行不参与列宽扩张，放不下时改显示“<30M”，保持单行。两行和三行高度分别按实际排版测量并 lazy 缓存；Short 状态变化只更新按钮和该行，左右两侧行高同步，底色随行底色变化，描边统一。
- **代码：** IpDownloadSpeed.kt 共用请求构造；IpSpeedTestCoordinator.kt 管理事件互斥；SavedIpActivity.kt 处理点击与保存；SavedIpStore.kt 保存两列速度及 Short 标记；SavedIpDesign.kt 和 IpTestView.kt 原位更新按钮与行高。
- **功耗 / 计算量：** 不新增定时器、轮询、后台任务或网络请求；只有用户点击按钮才下载。Short 状态变化只处理当前行的两个按钮高度和左右行容器，不遍历其他行、不重建整表。\n- **验证：** 静态核对请求参数、旧数据迁移、双列速度与 Short 标记保存、互斥、三行提示和行级高度同步；未运行 Android 编译或真机测速。
