## 158. 已保存 IP 独立直连 / 经节点下载测速

- **入口：** 已保存 IP 表有“直连测速”和“经节点测速”两列，均可单独触发；结果分别保存，不覆盖另一列。
- **请求：** 复用配置检查页现有 kind=ip、mode=download 下载测速请求，不另建下载实现。直连请求 node 为空；经节点使用配置检查页保存的 ip_node，并先校验节点存在。两种模式分别复用各自下载 URL 偏好。
- **旧数据：** 旧 speed 按 testDirect 迁移到 speedDirect 或 speedNode；未测值为 0 / sentinel，不自动发起测速。
- **互斥与功耗：** 与配置检查页 IP 测试 / 下载测速共享事件驱动互斥；只在用户点击时发起，不用定时器、轮询或后台任务。测速状态变化只更新当前已绑定按钮，不重建整表。
- **结果更新：** 测速结束只更新对应行的对应速度按钮；若当前启用了该列排序，仅移动现有行 View 到新位置，不重建表格、列宽或行高。
- **布局：** 两列按钮顶部对齐，背景随所在行底色变化，描边统一；行高由 IP 格、结果文字格和测速按钮格中最高者决定。
- **代码：** IpDownloadSpeed.kt 共用请求构造；IpSpeedTestCoordinator.kt 管理事件互斥；SavedIpActivity.kt 处理点击与保存；SavedIpStore.kt 保存两列速度；SavedIpDesign.kt 和 IpTestView.kt 原位更新行。
- **验证：** 静态核对请求参数、旧数据迁移、双列保存、互斥和行级更新；未运行 Android 编译或真机测速。
