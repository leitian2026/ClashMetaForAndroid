## 158. 已保存 IP 显示平均延迟和下载速度

- **保存数据：** 已保存 IP 条目新增平均延迟 `avg`（毫秒）和下载速度 `speed`（MB/s）。保存测试结果时，从对应的 `IpTestRow.avg`、`IpTestRow.speed` 写入；同一批次重复地址以后出现的测试结果覆盖前一条的指标，与通断状态、测试时间的更新方式一致。
- **旧数据兼容：** 新字段默认分别为 `0` 和 `0.0`，旧版 JSON 无需迁移即可读取；未测试或没有对应指标时显示短横线。
