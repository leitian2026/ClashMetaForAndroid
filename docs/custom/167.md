## 167. 配置检查页测 IP 表精简 / 完整显示列

- **入口：** 测 IP 表上方显示“显示列：精简 | 完整”切换，默认完整；当前模式用 ✓ 标出。精简和完整共用一个 SharedPreferences 文件 `custom_iptest_ui`、一个键 `compact_columns`，三种测试模式共用设置。
- **精简列：** IP 固定列不变；保留端口（直连显示端口检测结果，节点模式显示节点端口）、失败率、平均延迟、下载测速按钮和速度。带目标网址的模式额外保留“目标站反应”。其他机房、运营商、归属地、落地、最小 / 最大延迟、抖动、出口 IP、分段耗时等列隐藏。
- **布局：** 当前模式的可见列决定表头、单元格和 `widths()` 宽度计算；切换只用已有结果重新绘制表格，不发起测试、不清空测试结果，并恢复原有横向滚动位置。按钮不显示在已保存 IP 表。
- **数据与导出：** 内存中的完整 `IpTestRow` 和已保存快照不变；`plain()` 始终按完整列输出，不受精简模式影响。已保存页原有自选列设置和渲染逻辑不受影响。
- **资源：** 新增英文和简体中文字符串到 `design/src/main/res/values/strings_custom.xml`、`design/src/main/res/values-zh/strings_custom.xml`。
- **版本：** `CUSTOM.md` 当前版本更新为 `2_11_46-r326`。
- **改动文件：** `IpTestView.kt`、中英文 `strings_custom.xml`、本详情及 `CUSTOM.md`。
- **验证范围：** 静态核对三种模式的精简列集合、SharedPreferences 单键、重绘复用已有结果、完整 `plain()` 导出和已保存表隔离；未运行 Android 构建或设备测试。
