## 169. 按运营商自动切换节点，代理页顶部增加设置入口

### 触发规则

- 只有两个触发入口：
  1. #168 的网络识别完成、NetworkIdentityStore.write() 落盘后，由 NetworkRetest.identify() 调用 CarrierSwitch.applyAsync()。#168 已按网络签名缓存，同一签名命中缓存时不会再次识别，也不会重复套用。
  2. 用户在运营商设置页保存映射后，先写 CarrierSwitchStore，再通过 IClashManager.applyCarrierSwitch() 调用同一套服务端匹配和切换逻辑；只读取当前已缓存的识别结果，不重新发起网络识别。
- 不在 Clash 启动、配置载入或订阅更新后重新套用映射。因此用户在同一网络里手动改节点，不会被启动或换配置流程改回去。
- 未知分类但保留了非空 rawOperator 时，允许自定义关键词匹配原始运营商文字；若 operator 和 rawOperator 都为空 / 未知、识别有错误或两个接口不一致，则不切换。
- 不关闭旧连接，不增加定时器、轮询、监听器、广播接收器、危险权限、JNI 或 mihomo patch。

### 识别快照扩展（#168）

- NetworkIdentitySnapshot 新增 rawOperator、switchResult、switchError：
  - 在线识别把接口运营商原文末段写入 rawOperator；移动数据 MCC/MNC 本地识别时留空。
  - switchResult 只记录 Clash 正在运行且 Clash.patchSelector() 成功后的“组 / 节点”。
  - switchError 记录切换失败时的“组 / 节点”；该失败计入 #168 网络错误和首页问题数。
- NetworkIdentityStore JSON 同步读写三个字段。旧版本 JSON 缺少字段时用 optString(..., "")，升级后正常读取，不因缺字段失败。

### 映射存储与匹配

- 新增 common/.../CarrierSwitchStore.kt，用 AtomicFile 按配置 UUID 保存 JSON：电信、联通、移动三个固定映射，以及按顺序保存的自定义项（keyword / group / node）。自定义列表不设条数上限。
- 映射文件只有主进程设置页写入；服务进程只在上述两个触发点读取一次，不监听文件变化、不轮询。
- 匹配优先级：先按自定义列表顺序检查填写了省 / 市的项目，省 / 市以忽略大小写的包含匹配检查识别结果的 province 或 city；关键词非空时还必须同时命中 operator 或 rawOperator，关键词为空时只按省 / 市匹配。之后再检查电信 / 联通 / 移动固定映射，最后检查未填写省 / 市的旧自定义关键词项目。旧 JSON 缺少 region 时按空字符串读取，旧项目行为不变。没有组或节点的映射不切换。
- 配置 UUID 读取 ServiceStore.activeProfile，与 ClashManager.patchSelector() 使用的配置归属一致。

### 备份与恢复（#17）
- 运营商映射作为订阅 manifest 项的可选 `carrier` 键导出；空映射不写入。恢复时通过 `idMap` 把备份 UUID 对应到恢复后的本机 UUID。
- 新订阅恢复映射；本机已有同名订阅只有在本机映射为空或 `replace = true` 时才覆盖。云端安全副本也经过同一导出路径，撤销时可还原。
- 映射 JSON 编码 / 解码统一由 `CarrierSwitchStore` 提供。

### 服务端执行

- 新增 service/.../custom/CarrierSwitch.kt。所有匹配、JNI 和数据库操作都在工作线程 / IO 调用路径执行。
- Clash 正在运行：调用 Clash.patchSelector(group, node)；成功后写入 SelectionDao().setSelected(Selection(uuid, group, node))。失败时只记录统一的“切换失败”错误，错误内容带组名和节点名；不尝试区分组不存在、节点不存在或非 Selector 组。
- Clash 未运行：只写 SelectionDao，由既有 ConfigurationModule 在下次载入配置时套用；此时不把“已预设”伪报成已经切换成功，也不记录失败。
- 写入 switchError / switchResult 后复用 ACTION_ISSUES_CHANGED 刷新首页和诊断页。成功不弹通知、不改首页卡片文案；错误与诊断页“网络识别”块显示成功结果。

### 设置页与代理页入口

- 新增 app/.../custom/CarrierSwitchActivity.kt 和 design/.../custom/CarrierSwitchDesign.kt。
- 设置页读取当前活动配置 UUID；组列表来自 queryProxyGroupNames(true)，节点列表来自每个可手动选择组的 queryProxyGroup(group, ProxySort.Default)，仅展示 Selector 组和非组节点。
- 电信、联通、移动三项可选择组、再选节点或清除；自定义项可新增、修改、删除，顺序保持不变。保存后先写入当前配置 UUID 对应的映射文件，再尝试对当前缓存识别结果立即套用。
- 代理页顶部在 ⚡ 左侧新增同尺寸入口图标，底部悬浮测速按钮不变。通过 setClassName 打开设置页；标题和返回栏剩余宽度需在窄屏设备上实测。
