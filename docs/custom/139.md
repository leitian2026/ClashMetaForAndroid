## 139. 将运行中的问题纳入诊断包（r162）
- **诊断包：** 内核运行时在 `errors.json` 同一位置读取 `SORT_ISSUES`，另存为 `issues.json`，保留全部条目（包括已忽略、已恢复）。已成功解析时，在 `summary.txt` 增加未忽略未恢复、已忽略、已恢复三类数量；读取或解析失败则不写该行。
- **说明：** 更新诊断包入口摘要和确认文案，明确包含运行中的问题，并保留节点服务器地址及失败域名的发送前检查提醒。#29 增加了 `issues.json`。
- **改动文件：** `DiagnosticBundle.kt`、design 中英文 `strings_custom.xml` 和本登记文件。
- **验证：** 已核对 `SORT_ISSUES = 10`、IssuesSnapshot 的 ignored / resolved 字段及导出路径；未运行 Android 编译或实测。
