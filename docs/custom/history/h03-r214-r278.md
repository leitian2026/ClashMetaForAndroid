## IP 测试审查修正（r220）
- **取消句柄竞态：** `beginRun()` 为每轮分配递增代号；旧轮次的 `done()` 只有在代号仍匹配时才清空取消句柄，避免误清新一轮的取消入口。批量 direct/node 与单 IP 测试共用该入口。
- **ALPN：** 经节点请求的自定义 `http.Transport` 显式设置 `ForceAttemptHTTP2`，避免自定义 `DialContext` 导致 Go 不尝试 HTTP/2。
- **归属地查询：** 自动 direct / node 测试不再请求 `ipinfo.io` 或 `ipwho.is`；只有用户触发 `asn`（查询归属地）模式才请求。成功或部分成功的结果按 IP 缓存在进程内，失败不缓存、不后台重试。节点测试原有入口机房读取保留，它不是 IP 注册归属地。
- **ECH 与 TLS 1.2：** ECH 握手因协议版本不兼容失败时，回退普通 TLS 握手；TLS 1.2-only 地址不再仅因 ECH 强制 TLS 1.3 被判为不可连接，ECH 状态留空表示未知。
- **节点线路匹配：** 通过域名推断配置节点时只匹配实际 `server`，不再因 `servername` / `sni` 相同误选其他入口。
- **Cloudflare 机房列表：** 同一进程内首次成功后缓存城市与国家码；同一 JSON 只解码一次。
- **重复逻辑：** 合并域名节点副本创建；统一 TLS 版本显示转换。
- **核对后不删除：** `parseTargets` 已逐行剥离 `#备注`；`runDirect` / `runNode` 仍由当前 `RunIP` 调用；`ConfigOmitted` / `ConfigFamily` 由配置读取结果赋值，不是死字段。故不按审查摘要删除这些逻辑。
- **验证：** 增加取消竞态单测；本次未运行 Go 测试、Kotlin 编译或 Android 构建。
