## 97. 测速失败表格只显示 HTTP 状态码（r113）

- **日志：** 完整原始错误仍只写入实时日志，保持单行；不改变错误记录内容。

- **改动文件：** design/src/main/java/com/github/kr328/clash/design/custom/IpTestView.kt 和本登记文件；没有修改上游文件总表。
