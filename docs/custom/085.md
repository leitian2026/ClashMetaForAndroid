## 85. 测 IP 总数和已测数量显示在测试模式标题行

- **显示位置：** 配置检查页 IP 测试表上方的模式标题（例如“经节点延迟测试（节点 ipv4）”）保持原文，右侧同一行显示“共 N 个 IP，已测 M 个”。不再把数量拼到下方“实时状态”日志标题。
- **计数规则：** 总数取内核解析后的本轮实际测试列表（遵守去重、直连 / 套入节点规则及 20 个上限）；已测数在每个 IP 探测返回结果后递增，失败但已返回的探测也计入，取消时尚未完成的当前探测不计入。测试开始显示 0，进度随每个 IP 完成即时更新。
- **颜色：** 总数段浅色模式为深绿 `#2E7D32`、夜间模式为浅绿 `#81C784`；已测段浅色模式为更深绿 `#1B5E20`、夜间模式为 `#66BB6A`。进度位于模式标题行右侧，空间不足时标题可省略，不改变表格宽度或行高。
- **复制：** 复制 Markdown 仍在“实时状态”标题后保留“共 N 个 IP，已测 M 个”原句。
- **功耗：** 继续由现有测试结果事件更新，不增加额外请求、定时器、轮询或后台任务。
- **改动文件：** `design/src/main/java/com/github/kr328/clash/design/custom/IpTestView.kt`、本登记文件及 `CUSTOM.md` 索引；不改 Activity、Go 或 mihomo。
- **验证：** 完成源码静态检查；未运行 Android 编译或真机 UI 验证，需用户手动构建确认窄屏标题省略及复制内容。
