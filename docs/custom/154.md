## 154. 勾叉改为“实心圆 + 白色勾 / 叉”的图标（r175）
- **图标：** 整个 app 所有 ✓ / ✔ 画成绿色实心圆里一个白色的勾，✗ / ✘ 画成红色实心圆里一个白色的叉（和 GitHub Actions 的状态图标一致）。勾叉用 `Path` 线条绘制（圆头线帽、圆角连接），不再用字体字形，也不再有“勾叉 + 圆点”两样东西。
- **颜色：** 圆沿用 #153 的 `MARK_DOT_GOOD`（`#00E676`）和 `MARK_DOT_BAD`（`#FFFF1744`），不变，不随主题变化；勾叉固定白色。`good(context)` / `bad(context)` 和日夜判断已无人使用，一并删除。
- **大小与对齐：** 圆的直径为字号 × 0.6 取偶数像素（r175 为 1.05，比旁边的字大一圈，r176 改为比字小一圈），圆心取整；图标后面留字号 × 0.2 的间距（文字里 ✓ 后面多半已有空格，端口列的 ✗443 没有，所以保留一点）。圆保留 0.5 px 同色描边（半径相应减去 0.25 px，总直径不变）。勾叉线宽为直径的 0.12 倍。
- **范围：** 只改 `CheckMark.kt` 的 `MarkSpan`，所有调用点（首页卡片、配置历史、编辑器历史选择、DNS 检查、测试 IP 端口列）不动，底层文字不变，复制和导出仍是 ✓ / ✗。代理页“在用”圆点（#151、#152）不动。取代 #149、#153 中关于勾叉后圆点的绘制方式。
- **功耗：** 只是绘制，无定时器、轮询或动画。
- **改动文件：** `design/.../custom/CheckMark.kt` 和本登记文件。
- **验证：** 静态核对 `getSize()` 与 `draw()` 的宽度一致、`good(context)` / `bad(context)` 再无引用、各调用点仍走 `CheckMark`；未运行 Kotlin 编译、Android 构建或真机显示测试。
