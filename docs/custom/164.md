## 164. 已保存页顶部、分组筛选、表头筛选与速度排序（r304）

- **范围：** 仅修改已保存 IP 页面；普通 IP 测试页和 mihomo 不变。不新增定时器、轮询或后台任务。
- **顶部：** 搜索控件移动到“已保存的 IP”标题行右侧；删除原筛选工具栏整行，包括“全部”“落地国家”“排序”按钮及对应菜单逻辑。
- **状态筛选：** 每个运营商标题行内显示“通 / 不通 / 未测试”三个可点击彩色标签。标签可多选；选择的状态按 OR 匹配，同组全取消时不过滤。状态集合以运营商 ID 分开保存，点击联通标签只过滤联通组，不影响移动、电信。标签计数显示该组完整保存清单中的对应状态数量。
- **表头筛选：** 保留 #160 的入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站反应文字列筛选。选项只取当前运营商已有结果的非空、非“-”显示值；数据变化时仅校正该组的已选值。每个运营商的列筛选独立保存；同列多选 OR，不同列 AND，并与状态筛选、搜索 AND 组合。没有任何列筛选时，旧 IP（无测试快照）正常显示；选择列值后无该列值的旧 IP 被过滤。数字列、分段耗时、测试不可点击。
- **速度排序：** 仅点击“速度”表头打开“按最快”“按最慢”两个选项；再次点击当前选项取消，恢复默认测试时间新到旧。当前方向显示在速度表头下方。速度为 0 / 无数据的 IP 永远置后，同速保持默认顺序；所有延迟列不参与排序。
- **状态恢复：** 各运营商状态集合、各运营商各列筛选、速度排序、搜索关键词和展开状态由 SavedIpFilterState.kt 通过实例状态保存与恢复；不写入保存数据。
- **布局约束：** IP 固定列、列宽、横向滚动和数据行不改；速度摘要只在现有速度表头单元格下方显示，不改变固定 IP 列和滚动容器结构。
- **修改文件：** SavedIpDesign.kt、IpTestView.kt、SavedIpFilterState.kt、SavedIpSort.kt、CUSTOM.md、docs/custom/156.md、docs/custom/159.md、docs/custom/160.md、本详情文件。
- **自主处理：** 表头筛选按运营商独立（用户确认方案 A）；速度排序保持全页面同一排序方向，并在每个运营商组内独立排序；状态标签计数按该组完整保存项统计，避免选中状态后其他标签计数随过滤缩小。
- **验证范围：** 静态核对筛选作用域、组合逻辑、状态保存键、速度排序方向与无速度置后；未运行构建、未触发 Actions、未打包、未做真机交互测试。
