## 164. 已保存页顶部、分组筛选、表头筛选与速度排序（r307）

- **范围：** 仅修改已保存 IP 页面；普通 IP 测试页和 mihomo 不变。不新增定时器、轮询或后台任务。
- **顶部：** 搜索控件移动到“已保存的 IP”标题行右侧；删除原筛选工具栏整行，包括“全部”“落地国家”“排序”按钮及对应菜单逻辑。
- **状态筛选：** 每个运营商标题行内显示“全部 / 通 / 不通 / 未测试”四个可点击标签，单选互斥；默认选中“全部”，选择“通 / 不通 / 未测试”后仅显示对应状态，再点“全部”清除状态条件。每个运营商的选择独立，点击联通标签只过滤联通组，不影响移动、电信。标签计数显示该组完整保存清单中的对应状态数量。“全部”计数为该组 IP 总数。状态筛选与表头各列筛选、搜索按 AND 组合。
- **搜索匹配（r314）：** 搜索不只匹配 IP 地址，还匹配当前运营商已保存表中入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站响应的单元格显示文字；不区分大小写。显示值直接复用 `IpTestView.savedTableFilterValue(entry, columnIndex)`，国家使用表格的中文显示名，不另建映射。与状态筛选、表头筛选按 AND 组合；搜索时所有匹配运营商仍全部展开。输入时关键词和搜索指示立即更新，表格重建延迟约 300 ms；新输入取消并重排一次性延迟任务。清空搜索、点击输入法搜索、关闭 / 折叠搜索框时立即重建；其他刷新或局部重建会取消待执行任务。页面 onStop / 销毁时取消待执行任务，恢复前台时若关键词与最后渲染值不同则补做一次重建。
- **表头筛选：** 保留 #160 的入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站反应文字列筛选。选项只取当前运营商已有结果的非空、非“-”显示值；数据变化时仅校正该组的已选值。每个运营商的列筛选独立保存；同列多选 OR，不同列 AND，并与状态筛选、搜索 AND 组合。没有任何列筛选时，旧 IP（无测试快照）正常显示；选择列值后无该列值的旧 IP 被过滤。数字列、分段耗时、测试不可点击。
- **速度排序：** 仅点击“速度”表头打开“按最快”“按最慢”两个选项；再次点击当前选项取消，恢复默认测试时间新到旧。当前方向显示在速度表头下方。速度为 0 / 无数据的 IP 永远置后，同速保持默认顺序；所有延迟列不参与排序。
- **状态恢复：** 各运营商单项状态选择、各运营商各列筛选、速度排序、搜索关键词和展开状态由 SavedIpFilterState.kt 通过实例状态保存与恢复；不写入保存数据。
- **布局约束：** IP 固定列、列宽、横向滚动和数据行不改；速度摘要只在现有速度表头单元格下方显示，不改变固定 IP 列和滚动容器结构。
- **修改文件：** SavedIpDesign.kt、SavedIpFilterState.kt、SavedIpSort.kt、CUSTOM.md、docs/custom/156.md、docs/custom/159.md、docs/custom/160.md、本详情文件。
- **自主处理：** 表头筛选按运营商独立（用户确认方案 A）；速度排序保持全页面同一排序方向，并在每个运营商组内独立排序；状态标签计数按该组完整保存项统计，避免选中状态后其他标签计数随过滤缩小。
- **验证范围：** 静态核对单选状态筛选、与表头筛选及搜索的 AND 组合、状态保存恢复和速度排序方向；静态核对搜索列索引与既有单元格显示值映射；未编译。
