## 164. 已保存页顶部、分组筛选、表头筛选与双测速列排序

- **范围：** 仅修改已保存 IP 页面；普通 IP 测试页和 mihomo 不变。不新增定时器、轮询或后台任务。
- **顶部：** 搜索控件移动到“已保存的 IP”标题行右侧；删除原筛选工具栏整行，包括“全部”“落地国家”“排序”按钮及对应菜单逻辑。
- **状态筛选：** 每个运营商标题行内显示“全部 / 通 / 不通 / 未测试”四个可点击标签，单选互斥；默认选中“全部”，选择“通 / 不通 / 未测试”后仅显示对应状态，再点“全部”清除状态条件。每个运营商的选择独立，点击联通标签只过滤联通组，不影响移动、电信。标签计数显示该组完整保存清单中的对应状态数量。“全部”计数为该组 IP 总数。状态筛选与表头各列筛选、搜索按 AND 组合。
- **搜索匹配（r314）：** 搜索不只匹配 IP 地址，还匹配当前运营商已保存表中入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站响应的单元格显示文字；不区分大小写。显示值直接复用 IpTestView.savedTableFilterValue，国家使用表格的中文显示名，不另建映射。与状态筛选、表头筛选按 AND 组合；搜索时所有匹配运营商仍全部展开。输入时关键词和搜索指示立即更新，表格重建延迟约 300 ms；新输入取消并重排一次性延迟任务。清空搜索、点击输入法搜索、关闭 / 折叠搜索框时立即重建；其他刷新或局部重建会取消待执行任务。页面 onStop / 销毁时取消待执行任务，恢复前台时若关键词与最后渲染值不同则补做一次重建。
- **表头筛选：** 保留 #160 的入口机房、入口运营商、登记国家、落地国家、端口、出口 IP、目标站机房、目标站反应文字列筛选。选项只取当前运营商已有结果的非空、非“-”显示值；数据变化时仅校正该组的已选值。每个运营商的列筛选独立保存；同列多选 OR，不同列 AND，并与状态筛选、搜索 AND 组合。没有任何列筛选时，旧 IP（无测试快照）正常显示；选择列值后无该列值的旧 IP 被过滤。数字列、分段耗时、测试不可点击。
- **筛选选项计数（本次补充）：** 点开已保存页任一可筛选列的表头弹窗时，按当前运营商的完整 IP 清单计算每个选项对应的可见行数。计数依次应用当前运营商的状态筛选（通 / 不通 / 未测试）、其他列已勾选条件、当前搜索词；本列自己的勾选条件不参与计数。同列多选时各选项数字保持不变。选项仍来自该运营商完整清单，计数为 0 的选项也保留并显示 0。顺序不按计数调整。仅在打开弹窗时遍历并计算一次，弹窗内勾选不刷新数字，关闭后重新打开才重新计算。中文显示“选项 4个”，英文显示“选项 4”。显示文字与原始筛选值分离：CheckBox 的文字附加计数，tag 和筛选集合仍使用原始值，筛选匹配不使用附加计数的文字。长选项可由 CheckBox 自动换行，不改变弹窗宽高计算。
- **零匹配结果表头：** 当某运营商启用了状态或表头筛选且最终结果为 0 条时，仍保留该运营商分组，并在空结果提示上方调用 `bindSavedTable(section, operator, emptyList())` 绘制正常表头。列名和筛选入口继续使用原有点击回调，仍可打开筛选框、修改选项或清除筛选；筛选弹窗的匹配行数计算不变。空列表同样生成吸顶表头副本，并沿用主表格与副本之间的横向滚动同步；多选模式下仍按原逻辑预留复选框列宽。无筛选且正常有结果时不额外绘制空表头。
- **速度排序：** 直连测速、经节点测速两个表头均可点击并分别弹出“按最快 / 按最慢”。同一时间只保留一个测速列和一个方向；切换列会取消前一列，方向标签只显示在当前列下方。按最快从大到小，按最慢从小到大，只比较当前列自己的 speedDirect 或 speedNode；0 / 未测始终置后，同速保持默认顺序。再次选择当前方向取消排序，恢复默认测试时间新到旧。
- **状态恢复：** 各运营商单项状态选择、各运营商各列筛选、测速列与方向、搜索关键词和展开状态由 SavedIpFilterState.kt 通过实例状态保存与恢复；旧版没有测速列信息的 SPEED_ASCENDING / SPEED_DESCENDING 状态安全回退默认顺序；不写入 IP 保存数据。
- **计算与更新：** 默认时间顺序按数据版本缓存；测速排序只对当前明确展开的运营商组计算，并按数据版本与排序选项缓存。滚动和绘制不触发排序、列宽或行高计算；筛选只从缓存顺序中筛行。测速结果更新现有速度按钮并按新顺序移动既有行 View，不重建整张表。
- **布局：** 两个测速表头均可排序，固定显示名称、MB/s、排序标签三行；测速按钮固定两行高度，第一行只显示“直连 / 经节点”，第二行只显示一位小数速度值，不带单位，未测速时保留空行；测速中、成功、失败只更新按钮文字，不改变按钮高度和位置。完整名称资源继续用于自选列和完成提示。按钮沿用行底色，按钮和文字单元格共同参与行高测量；普通文字最多三行。
- **修改文件：** SavedIpDesign.kt、SavedIpFilterCounts.kt（本次新增，单次遍历计数纯函数）、values/strings_saved_filter_count.xml、values-zh/strings_saved_filter_count.xml、SavedIpFilterState.kt、SavedIpSort.kt、IpTestView.kt、SavedIpActivity.kt、CUSTOM.md、docs/custom/159.md、本详情文件。
- **自主处理：** 表头筛选按运营商独立（用户确认方案 A）；状态标签计数按该组完整保存项统计，避免选中状态后其他标签计数随过滤缩小。
- **验证范围：** 静态核对筛选与搜索组合、双测速列排序、状态保存恢复和行级速度更新；未运行 Android 构建或真机交互。
