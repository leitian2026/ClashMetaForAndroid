## 161. 配置检查页测 IP 表头和下载按钮固定分行，按文字实测宽度保护列宽

- **问题：** 最小延迟、最大延迟、平均延迟、延迟波动四个中文表头在窄列中可能出现末行单字；下载测速按钮原来使用单行文案，52dp 列宽下可能自动断成三字加一字。
- **中文表头：** `iptest_col_min`、`iptest_col_max`、`iptest_col_avg`、`iptest_col_jitter` 分别显式写为“最小 / 延迟”“最大 / 延迟”“平均 / 延迟”“延迟 / 波动”，每行两个字，使用 XML `&#10;`。其他语言资源不改。
- **下载按钮：** 不改原有 `iptest_btn_speed`，新增按钮专用 `iptest_btn_speed_button`；中文页面使用“下载 / 测速”，默认回退值为 `Download`。按钮按页面语言选择：中文使用新字符串，英文及其他语言继续使用原有 `iptest_btn_speed`，不丢失原有翻译。按钮最多两行，最小高度按实际字体行高计算并留出垂直内边距，使两行文字能完整显示。
- **列宽：** `IpTestView.widths()` 对当前列标题按实际字体、字号、字重测量最长显式行宽，并加上表头左右内边距；下载按钮按按钮自身字体测量最长一行并加按钮左右内边距。每列最小宽度取原有宽度与实测需求的较大值。原有 15% 收窄只有在不低于表头 / 按钮的实测最小宽度时才采用；否则保留自然宽度并沿用表格横向滚动。
- **布局：** 同一套测量逻辑用于直连测、套入节点测、带目标网址三种列组合。表头没有设置 `maxLines`，不需要调整；未改表格列顺序、横向滑动容器、测速行为、排序、导出或复制，也未加入定时器、动画和轮询。
- **改动文件：** `IpTestView.kt`、中文 `strings_iptest.xml`、默认 `strings_iptest.xml`（只新增英文回退资源）、本详情及 `CUSTOM.md`。没有修改其他语言资源。
- **相关详情：** #62（测 IP 表格列宽和速度列）、#63（套入节点测列组合）、#94（表格行高和表头布局）。
