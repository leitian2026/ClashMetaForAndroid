## 161. 配置检查页测 IP 表头“下载测速”固定分两行显示

- **问题：** 直连及套入节点测 IP 表格的“测速”操作列宽固定为 52dp；中文“下载测速”四字在该列宽下自动换行，可能拆成“下载测 / 速”，末字挤在下一行。
- **修改：** 仅将中文资源 `iptest_col_test` 改为显式两行“下载 / 测速”，列宽保持 52dp。英文资源仍为单行 `Download`，无需调整。
- **布局核对：** `IpTestView.headCell()` 允许标题换行；`redraw()` 通过 `heightOf()` 测量各表头实际高度，并以最高表头计算统一表头高度，因此两行标题可以参与现有高度计算。
- **屏幕布局：** 未修改 `IpTestView.width()`、`widths()` 或列顺序；“速度”列继续按既有逻辑留在屏幕右侧外，需要横向滚动查看。
- **改动文件：** 修改 `design/src/main/res/values-zh/strings_iptest.xml`、`CUSTOM.md`；新增 `docs/custom/161.md`。未改 `IpTestView.kt`，未改上游文件。
- **相关详情：** #62（表格列宽、速度列与表头高度）、#94（表格行高和表头布局）。
- **验证：** 已核对英文资源仍为 `Download`，中文资源为显式两行；未实际运行 `bash scripts/check-custom.sh`，未执行 Android 编译或真机测试。
