## 153. 勾叉后圆点放大、满饱和、像素对齐（r174）
- **范围：** 整个 app 所有 ✓ / ✗ / ✔ / ✘ 后面的圆点都走 `CheckMark.MarkSpan`（首页卡片、配置历史、编辑器历史选择、DNS 检查、测试 IP 端口列），只改这一处，各调用点不动。
- **颜色：** 勾叉后的圆点改用新常量 `MARK_DOT_GOOD = -16718218`（`#FF00E676`）、`MARK_DOT_BAD = -59580`（`#FFFF1744`），均为满饱和，不随主题变化。原 `DOT_BAD` 已无人使用，删除；`DOT_GOOD`（`#4ADE80`）只留给代理页“在用”圆点（#151、#152），不变。本条取代 #152 里“所有自定义圆点只用 `#4ADE80` / `#FF6B6B`”中关于勾叉圆点的部分。
- **大小：** 直径由字号 × 0.5 改为字号 × 0.65 并取偶数像素，前后间距各为字号 × 0.25 取整。
- **清晰度：** 圆心 x、y 取整，直径为偶数像素，圆的边缘落在像素边界上；`getSize()` 对勾叉字形宽度向上取整，与 `draw()` 用同一套整数宽度，位置不再有半像素误差；圆加一圈 0.5 px 同色描边（半径相应减去 0.25 px，总直径不变），让抗锯齿的边缘像素更实。
- **功耗：** 只是绘制时多几次取整，无定时器、轮询或动画。
- **改动文件：** `design/.../custom/CheckMark.kt` 和本登记文件。
- **验证：** 静态核对两个颜色常量的有符号十进制值、`getSize()` 与 `draw()` 的宽度一致、各调用点仍走 `CheckMark`；未运行 Kotlin 编译、Android 构建或真机显示测试。
